# Простое производство

- `app/pages/` содержит маршруты главной, складов и настроек, а также вход и активацию.
- `app/features/` содержит интерфейс и логику разделов. Общие карточки настроек и планировщик резервного копирования подключаются из `@obshaya/ui`.
- `endpoints/warehouse/<operation>/` содержит типы, сервис и стор для каждой операции со складами.
- Серверное направление и префикс хранилища приложения используют идентификатор `production`.

Запуск из корня репозитория: `npm.cmd run dev:production`. Адрес по умолчанию — `http://localhost:3003`.

Для активации через рабочую админку нужно применить миграцию `0003_production_product.sql` и развернуть обновлённые API и админку.
