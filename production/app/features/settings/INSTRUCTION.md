# Настройки «Простого производства»

Маршрут `/settings` содержит смену PIN, проверку и скачивание обновлений, экспорт и импорт JSON, выбор двух папок и расписание резервных копий.

- Страница подключает карточки и функции резервного копирования из `@obshaya/ui`.
- С включённой облачной копией очередной цикл обновляет `production-backup.json` в выбранных папках и архив устройства в админке. Для записи в папки браузер должен поддерживать их выбор и иметь доступ на запись.
