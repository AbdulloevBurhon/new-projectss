# Продажи

Раздел открывается по адресу `/sales` из сайдбара. Вкладка «Продажа» содержит каталог изделий и корзину. Вкладка «История» показывает оплаченные корзины, дату, изделия и общую цену.

Название, фото и цена берутся из техкарты. Наличие рассчитывается для каждого склада по выпущенным и проданным дверям. Изделия одной техкарты с разных складов идут отдельными позициями. Для старых записей без места хранения используется группа «Без склада».

При оплате выбирают счёт. Цена по умолчанию берётся из корзины. Перед записью повторно проверяются счёт, сумма, цены позиций и доступное количество.

В модалке оплаты можно изменить цену одной двери, а для корзины из нескольких позиций — общую стоимость продажи. После выбора клиента «Оплачено» и «Долг» пересчитываются по новой цене. На счёт зачисляется только оплаченная сумма, а долг отображается в истории продажи и карточке клиента.

История сохраняет название склада на момент продажи. Отмена через историю убирает приход и возвращает количество на исходный склад. В карточке счёта операции продаж ведут в историю продаж.

- `components/` содержит каталог, корзину, оплату и историю.
- `stores/useSales.ts` загружает данные склада и рабочих и сохраняет продажи через хранилище счетов.
- `utils/sales.ts` рассчитывает наличие. Цены и суммы хранятся в сотых долях сомони.
