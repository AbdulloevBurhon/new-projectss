# Итоги

Раздел открывается по адресу `/summary` из сайдбара. Один фильтр по датам применяется ко всем карточкам. Обе даты включаются в период. Пустые поля означают, что соответствующая граница периода не задана.

- «Изготовлено изделий» считает записи о выполненных работах.
- «Начислено рабочим» суммирует начисления по этим работам.
- «Выручка от продаж» суммирует фактическую оплату сохранённых продаж.
- «Поступление материалов» суммирует стоимость позиций в складских поступлениях. Дата поступления берётся из журнала склада по местному времени.

`services/summary-sources.ts` читает существующие данные из хранилищ склада, рабочих и счетов. `utils/calculate-summary.ts` считает показатели, `composables/useSummary.ts` связывает данные с фильтром. Изменения в другом окне обновляют показатели через событие хранилища.
