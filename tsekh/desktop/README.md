# «Цех» для Windows

Из корня репозитория соберите EXE на Windows x64:

```powershell
volta run --node 22.22.3 npm ci
volta run --node 22.22.3 npm run desktop:build --workspace @obshaya/tsekh
```

Версия берётся из `tsekh/package.json`. Файл `Tsekh-<версия>-Windows-x64.exe` появится в `tsekh/release/`. Для запуска нужен Microsoft Edge WebView2 Runtime. Данные и активация хранятся в профиле `%LOCALAPPDATA%\Tsekh-4\profile`.

Для следующего выпуска увеличьте версию в `tsekh/package.json`, обновите lock-файл и соберите EXE. В админке откройте «Обновления», выберите направление «Цех», укажите ту же версию и загрузите файл. В настольном «Цехе» откройте «Настройки» → «Проверить обновление» → «Установить и перезапустить». EXE должен находиться в папке, доступной пользователю на запись. После входа новая версия сообщает об установке админке.

Для архивов выберите две папки и задайте интервал `0 ч 1 мин`. С включённой галочкой «Копировать в облако» каждый цикл обновляет `tsekh-backup.json` в двух папках и один архив устройства в админке. Файл, удалённый вручную, создаётся заново при следующем цикле. Копии создаются, пока «Цех» открыт и выполнен вход. Облачная копия требует доступного API и интернета.

Для облачной архивации обновите Worker из этой ветки. Маршрут `PUT /api/client/archives/latest` использует существующие D1 и R2. Ручной экспорт с облачной копией сохраняет отдельный архив.
