# Операторская админка и облако

[Главная карта](../../STRUCTURE.md)

Админка — отдельное приложение. Её входной экран в [`index.vue`](../../../admin/app/pages/index.vue). Оператор работает с установками «Цеха». Карточка покупателя из раздела «Клиенты» хранится в локальной SQLite.

| Вкладка | Где искать |
| --- | --- |
| Заметки | `admin/app/features/notes/`, обработчик Worker `handlers/admin/notes.ts` |
| Заявки и активация | `admin/app/features/requests/`, `handlers/admin/requests.ts`, клиентский `handlers/client/activation.ts` |
| Клиенты, ПИН и сообщения | `admin/app/features/clients/`, `handlers/admin/clients.ts`, `handlers/admin/messages.ts` |
| Обновления | `admin/app/features/updates/`, `handlers/admin/updates.ts`, клиентский `handlers/client/updates.ts` |
| Архивация | `admin/app/features/archives/`, `handlers/admin/archives.ts`, клиентский `handlers/client/archives.ts` |

Состояние интерфейса ищи в [`admin-state.ts`](../../../admin/app/features/admin-state.ts), запросы в `admin/admin-endpoints/`. Хранилища Worker — D1 для метаданных и R2 для файлов обновлений и архивов. Операторские маршруты `/api/admin/*` и клиентские маршруты `/api/client/*` используют разные правила входа.

В разделе «Клиенты» открой «Редактировать клиента», чтобы установить интервал Telegram для «Цеха» в минутах или часах. Ноль отключает расписание. Интервал сохраняется в лицензии через `PATCH /api/admin/clients/:id`. Устройство получает его при подключении к Worker. Для первой отправки клиент подтверждает получателя в «Цехе». Подробнее в [инструкции Telegram](telegram.md).

При ошибке активации сопоставь идентификатор установки и состояние заявки. При ошибке архивирования проверь разрешение клиента и вид отправки. При ошибке обновления сверь направление «Цех», версию и состояние файла. Для полного прогона используй тестовую установку, согласуй действия во внешней среде и пройди от заявки и одобрения до поддержки, ручной и плановой копий.

Перечень маршрутов, привязки ресурсов и команды обслуживания находятся в [документации Worker](../../../cloudflare/worker/README.md).
