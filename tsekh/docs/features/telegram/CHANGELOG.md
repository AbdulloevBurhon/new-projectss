# Журнал изменений — Telegram

- 2026-11-21 — В рабочей D1 применена миграция `0011`, Worker с текстовой доставкой развёрнут. Рабочий маршрут `/health` подтвердил запуск. Отправка нового комплекта в рабочий чат на момент проверки ещё не произошла.

- 2026-11-21 — Продажи и малые остатки отправляются текстом в чат. JSON-бэкап сохраняет формат импорта. На тестовой SQLite с имитацией Telegram проверены ручная отправка, очередь, длинный отчёт из 195 позиций, продолжение с неподтверждённой части и миграция прежнего прогресса доставки.

- 2026-11-21 — Ссылка подтверждения номера открывается в браузере Windows. На тестовом профиле собранного EXE проверено, что клик на карточке передаёт ссылку с параметром подтверждения обработчику браузера.

- 2026-11-21 — Интервал назначается в операторской админке. Очередь готовит комплекты без сети и хранит три свежих календарных дня. На тестовой SQLite и имитации Telegram проверены четыре дня офлайн, отправка трёх комплектов, возобновление с неподтверждённого файла и отмена отправки при интервале 0.

- 2026-11-21 — Отчёт об остатках показывает количество в единице складского остатка товара. Для «Картошки» действующий Nuxt API подтверждает строку «8 кг». На отдельной SQLite проверены кг, шт, граммы, упаковки, суммирование по складу и исключение порога 50. Ручной текст, TXT и отправка по расписанию проверены с имитацией доставки.

- 2026-11-21 — Расписание Telegram работает в сеансе сотрудника с ключом, который администратор получает при сохранении интервала. Через имитацию Telegram API проверены три файла, пропуск повторной отправки, отзыв ключа и совместимость с прежним Worker.

- 2026-11-21 — В файл малых остатков включаются позиции меньше 50 шт. или 50 кг. Проверены пересчёт граммов и упаковок, суммирование и исключение ровно 50.

- 2026-11-21 — Сверка разделена на три сообщения с файлами. В файл остатков включены товары до 15 шт. после пересчёта упаковок и суммирования по складу. Проверены порог, порядок отправки, частичная ошибка и старый формат.

- 2026-11-21 — Карточка видна при временном ПИН. Отправка становится доступной после сохранения постоянного ПИН при разрешённой облачной выгрузке. Проверена логика доступности.

- 2026-11-21 — Сверка показывает сумму погашений и текущий долг. Проверен локальный расчёт на тестовой базе.

- 2026-11-21 — Добавлена инструкция по привязке номера, расписанию и диагностике доставки текста и архива.
