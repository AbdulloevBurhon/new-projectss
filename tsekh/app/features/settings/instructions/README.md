# Настройки

[Главная карта](../../../../STRUCTURE.md)

| Карточка | Где искать |
| --- | --- |
| ПИН | `endpoints/access/license/`, облачная проверка и смена ПИН, [доступ](../../access/instructions/README.md) |
| Обновление | `endpoints/settings/updates/`, облачный список версий и подтверждения, [обновления Windows](../../../../desktop/README.md) |
| Архив данных | `composables/useSettingsArchive.ts`, `endpoints/settings/archive/`, `GET/PUT /api/data-archive`, `desktop/modules/archive/` |
| Папки хранения и резервные копии | `shared/ui/components/settings-workspace/`, в том числе `composables/useArchiveFolders.ts` и `useScheduledArchive.ts` |
| Отправка в Telegram | `components/TelegramDeliveryCard.vue`, [инструкция доставки](../../../../docs/features/telegram.md) |
| Принтер | Вкладка «Принтер», `components/ReceiptPrinterCard.vue`, `endpoints/settings/printer/` |

Ручная и плановая копии используют локальный снимок. Облачный ручной экспорт создаёт отдельный архив. Плановая отправка обновляет последнюю копию установки по `PUT /api/client/archives/latest`. Для облачной копии нужны интернет и разрешение в лицензии. Состояние каждой папки и облака проверяй отдельно.

В локальный снимок входят черновики и результаты [ревизий](../../revision/INSTRUCTION.md), а также сроки годности и остатки партий. Старые архивы восстанавливаются с теми данными, которые в них были сохранены.

При смене постоянного ПИН локальный API проверяет коды сотрудников. Пока облачный сервер сохраняет новый ПИН, локальная запись защищает выбранный код от параллельного назначения сотруднику.

При входе с временным ПИН настройки показывают подсказку, а карточка Telegram объясняет, как включить отправку. Сохрани постоянный ПИН, чтобы открыть рабочие разделы в текущем сеансе.

Карточка Telegram показывает интервал, назначенный оператором в админке. Клиент подтверждает номер получателя здесь. Открытый «Цех» сохраняет ожидающие комплекты за три последних календарных дня и отправляет их после восстановления связи.

Во вкладке «Принтер» укажи название магазина на чеке, выбери ширину 58 или 80 мм и способ подключения. USB-принтер появляется в списке после установки драйвера Windows. Для принтера LAN нужен IP-адрес и порт прямой печати ESC/POS, обычно 9100. «Пробная печать» использует текущие значения формы. После нажатия «Сохранить» эти значения применяются к продажам и повторной печати из отчётов. Предпросмотр меняется сразу.

Проверь установку ПИН и повторный вход, экспорт и импорт JSON на тестовой базе, выбор папок и запись по расписанию. Для обновления Windows проверь наличие подходящей версии, а после установки — отображаемую версию и подтверждение в админке.
