# Итоги

[Главная карта](../../../../STRUCTURE.md)

`/summary` показывает продажи за сегодня, последние 7 или 30 календарных дней. По умолчанию выбраны 7 дней, включая сегодня. Границы дней рассчитываются по местному времени устройства. Карточки, график и структура оплаты используют один результат запроса.

- «Продажи» суммирует `sales.total` за период. «Оплачено» суммирует `sales.paid` на момент продажи. «Продано в долг» показывает разницу этих сумм. Текущая задолженность с погашениями находится в разделе «Клиенты».
- «Чеки» показывает число продаж. Средний чек рассчитывается как сумма продаж, делённая на число чеков, с округлением до сотых долей сома. Клиент форматирует деньги в сомах.
- `GET /api/summary?boundaries=…` получает UTC-границы локальных дней. Общий [SQL](../../../../server/database/sales/summary.json) возвращает суммы и количество по дням. Nuxt обслуживает маршрут через `server/api/summary.get.ts`, Windows через `desktop/modules/sales/Summary.cs`.
- Сотруднику нужно право «Итоги». В расчёт входят только операции назначенных складов и счетов. Право «Отчёты» проверяется отдельно.
- Для сверки создай тестовые продажи с полной и частичной оплатой на разных счетах и складах. Проверь переход между днями, пустой день, средний чек и те же периоды в сеансе сотрудника с назначенными ресурсами.
