# Access feature changelog

- 2026-11-21 — Постоянный ПИН администратора учитывается при проверке уникальности. В браузере на отдельной базе проверены выход из администратора и вход по ПИН сотрудника.

- 2026-11-21 — Общий экран ПИН принимает ПИН сотрудника без отдельной кнопки. Проверены приоритет входа администратора, локальный вход, ошибка неверного ПИН, временный код и отказ при неактивной лицензии.

- 2026-11-21 — С общего экрана ПИН убрана кнопка входа сотрудника. Временный ПИН открывает настройки с указанием следующего шага. Проверены шаблоны и состояние при смене ПИН.

- 2026-11-21 — Добавлен переключатель входа сотрудника на экране ПИН. Локальный ПИН проверяется в SQLite. Проверены вход, выход и повторный вход через тестовый API.

- 2026-11-21 — Описаны активация, вход без сети и диагностика 401 в сообщениях поддержки.

- 2026-11-13 — added PIN entry, route gate, and support-message dialog scaffold.

- 2026-11-13 — добавлены глазок для PIN и автоматический вход после пятой цифры.

- 2026-11-13 — PIN-поле переведено на -model; автопроверка и глазок синхронизированы с общим Input.
- 2026-11-13 — экран PIN и поддержки вынесен в общий UI-пакет; для «Цеха» оставлена собственная проверка и сессия.
- 2026-11-13 — активация и проверка PIN подключены к Worker; добавлены проверка лицензии и отправка сообщений.
