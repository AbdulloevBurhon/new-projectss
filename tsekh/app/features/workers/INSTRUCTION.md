# Сотрудники

[Главная карта](../../../STRUCTURE.md)

- `/workers` показывает сотрудников из SQLite. Формы сотрудника, прав и отчёта расположены в `app/features/workers/components/`. Администратор может сменить ПИН сотрудника. После выхода сотрудник вводит свой код на общем экране ПИН. Постоянный ПИН администратора и ПИН сотрудников должны различаться. При создании и изменении сотрудника сервер проверяет занятые коды. Если в старых данных есть совпадение, администратор входит своим кодом и меняет ПИН сотрудника. Удаление сохраняет проведённые продажи.
- В форме сотрудника администратор раскрывает списки «Склад» и «Счёт» и отмечает конкретные позиции. Можно выбрать несколько. Одновременно открыт один список. Escape закрывает список и возвращает фокус на его кнопку. Списки открываются поверх формы. Пустой выбор запрещает операции с ресурсами этого вида. Настройки разделов и права на действия по-прежнему выдаются через ключ.
- Ограничения хранятся в `worker_resource_access` и входят в архив. У существующих сотрудников без настроенных списков до сохранения карточки сохраняется прежний доступ. Для них форма предварительно отмечает доступные позиции. Проверяй видимость списков, назначенный склад и счёт при продаже и отказ API для несогласованных позиций.
- Ключ открывает права по разделам. Права «Редактировать» и «Удалять» находятся внутри соответствующего раздела. Для продажи раскрой соответствующий раздел, чтобы выдать выбор склада и счёта, смену цены, скидку или продажу в долг.
- Запросы лежат в `endpoints/workers/`. Правила доступа — в `permissions.ts` в этой папке, проверка Nuxt — в [`worker-access.ts`](../../../server/middleware/worker-access.ts), работа с сотрудниками и сеансами — в [`workers.service.ts`](../../../server/services/workers/workers.service.ts). Для Windows используй `desktop/modules/workers/`.
- Для истории клиента нужно право «Клиенты». Чтобы сотрудник принимал оплату долга, в правах отметь «Клиенты → Погашать долг» и «Счёт». В карточке сотрудника назначь счета, на которые он может принимать оплату. Для сотрудников, которые уже могли принимать оплату, флажок «Погашать долг» при первом открытии прав установлен.
- При отсутствии раздела смотри меню в `app/app.vue`. Для ошибки запроса проверь действие и действующий локальный сеанс. При повторном входе загружаются актуальные права из SQLite. Открытый сеанс обновляет профиль раз в 10 секунд. Сервер отдельно проверяет права на каждый запрос.
- Кнопка «Информация» показывает продажи, долг и товары за период. Новые продажи под сотрудником связаны по идентификатору. Старые продажи без связи видны в [общих отчётах](../../../docs/features/reports.md).
- Проверь создание сотрудника, видимость ПИН в форме, сохранение прав, вход, запрещённое действие, продажу и фильтр отчёта по датам. После смены ПИН проверь старый сеанс и вход с новым кодом.
- Право «Склады» открывает [ревизию](../revision/INSTRUCTION.md) на доступных сотруднику складах. Проведение и отмена требуют права «Склады → Редактировать».
