# Клиенты и задолженность

[Главная карта](../../../../STRUCTURE.md)

- `/clients` содержит список клиентов, поиск и действия. Карандаш открывает форму имени и телефона. Корзина открывает подтверждение удаления. API отклоняет удаление клиента с продажами.
- `GET /api/sales/clients/:id` возвращает сумму покупок, текущий долг и историю покупок и погашений. Карточка использует таблицу с пагинацией. Остаток долга по покупке красный, погашение зелёное. Оплата уменьшает задолженность по старым покупкам первой.
- Кнопка «Погасить долг» находится в колонке «Действия» и активна при положительном долге. Она открывает `ClientDebtPaymentDialog.vue`. Принимать оплату может владелец или сотрудник с правами «Клиенты → Погашать долг» и «Счёт». При назначенных ресурсах доступны только отмеченные счета. Счёт и сумма передаются в `POST /api/sales/clients/:id/payments`.
- Сервер фиксирует платёж и зачисляет деньги одной транзакцией. Сумма платежа хранится в сотых долях сома. Повтор запроса с тем же ID и теми же данными зачисляется один раз. Nuxt и Windows используют [общий SQL](../../../../server/database/sales/client-payments.json).
- Погашения входят в JSON-архив. У клиента с покупками удаление ограничено ссылками на его чеки. Лицензии установок смотри в [админке](../../../../docs/features/admin.md).
- Проверь пустую историю, частичную и полную оплату, запрет переплаты, повтор запроса, отображение платежа на счёте и восстановление архива.
