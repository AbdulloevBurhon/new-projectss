# sales changelog

- 2026-11-21 — Продажа уменьшает остатки партий по ближайшему сроку в общей транзакции. На тестовой SQLite проверено списание с двух партий и исчезновение исчерпанной партии.

- 2026-11-21 — Каталог запрашивает по 15 товаров при прокрутке. Штрихкод ищется отдельным запросом по складу, а повторный скан использует полученный результат. На тестовой SQLite и в Edge проверены 500 товаров без пропусков и повторов, подгрузка, поиск по названию и скан последней позиции до прокрутки.

- 2026-11-21 — Клавиатурный ввод штрихкода перенесён в общий компонент с вкладкой «Поступление». В Edge повторно проверены добавление в корзину, ведущие нули, окно ошибки и работа поиска и оплаты.

- 2026-11-21 — В «Продаже» штрихкод принимается без отдельного поля. При отсутствии совпадения открывается окно с введённым кодом. В Edge проверены ввод и имитация сканера, ведущие нули, повторный скан, нехватка остатка, обычная работа поиска и оплаты и отключение перехвата при уходе со страницы.

- 2026-11-21 — В продажу добавлен ввод и сканирование штрихкода с Enter. В Edge на отдельной SQLite проверены коды `1` и `001`, повторный скан, ограничение склада, остаток, отдельная строка при изменённой цене, оплата и строки чека. Выдача штрихкода проверена через Windows C# и нативную SQLite.

- 2026-11-21 — Печать после оплаты использует сохранённый чековый принтер и название магазина. При ошибке принтера продажа остаётся сохранённой. На тестовой продаже проверено формирование печатного чека с клиентом и скидкой.

- 2026-11-21 — В списке товаров для продажи остаток отображается с точностью до двух знаков. Проверен пример 12,866666667 → 12,87. Расчёт использует исходное количество.

- 2026-11-21 — Продажа использует назначенные склады и счета. Проверены значения по умолчанию для кассира и отказ при выборе неназначенной позиции.

- 2026-11-21 — Кассир может открыть свой чек для печати без права просмотра всех отчётов. Проверены запись сотрудника в продажу и ограничения доступа к чужому чеку.

- 2026-11-21 — История клиента использует данные чеков и отдельные записи погашения. Проверено, что погашение сохраняет исходную оплату в чеке.

- 2026-11-21 — Убраны поля «Продавец» и «Роль» из оплаты. Проверены шаблон Vue и автоматическое заполнение для сотрудника и администратора.

- 2026-11-21 — Описаны действующий каталог, оплата, единицы товара и связанные проверки продажи.

- 2026-11-13 — created isolated feature scaffold; no business logic added.
