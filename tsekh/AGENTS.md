# Работа с «Цехом»

1. Начни с [главной карты проекта](STRUCTURE.md). Найди инструкцию нужной фичи и прочитай её перед правками.
2. При ошибке следуй [порядку диагностики](docs/diagnostics.md). При добавлении функции используй [план изменения](docs/change-guide.md).
3. Размещай код по назначению. Переиспользуй таблицы, формы и стили проекта. Держи исходные файлы фич короче 120 строк, выделяя модули по ответственности.
4. При изменении общего контракта проверь Nuxt и Windows. Для операций с данными используй изолированную тестовую базу.
5. Обнови инструкцию фичи при смене маршрута, источника данных, контракта или поведения. В конце каждой задачи добавь запись в `CHANGELOG.md` каждой затронутой фичи. При диагностике запиши вывод и фактически выполненные проверки. Найди нужный журнал в колонке «Журнал» на карте проекта.
