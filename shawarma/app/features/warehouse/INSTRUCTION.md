# Склады «Шаурмичной»

Маршрут `/warehouses` открывает список складов. Склад можно добавить, изменить и удалить. При создании указываются название и тип склада.

- В `app/features/warehouse/components/` находятся таблица и модальные окна.
- В `endpoints/warehouse/` находятся операции списка, добавления, изменения и удаления. У каждой есть файл типов, сервиса и стора.
- Склады хранятся в браузере и входят в JSON-архив направления `shawarma`.
